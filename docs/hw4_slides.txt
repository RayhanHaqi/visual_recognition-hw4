Output Format Example for Image Restoration
You are required to submit a file named pred.npz. This file should store all
restored images in a dictionary-like format using NumPy.
●

Keys are the filenames of the original images (e.g., '0.png', '1.png', …)

●

The values are the restored images. Each image should be stored as a
NumPy array with shape (3, H, W).
○

●

Shape explanation:
■ 3 channels (Red, Green, Blue)
■ Height and Width match the original image size
■ Values can be uint8 (0–255)
Submission may take some time, so it is better to prepare early and submit
on time.
